# 为什么 AI 不应该只"预测"，而应该学会"决策"？

> 🌍 EarthBench · 地球决策智能基准测试框架 | 2026-07-24

---

## 从 ChatGPT 到"行动派" AI 的一次范式转移

过去两年，大语言模型的能力令人目眩。

你能让它写代码、画图表、分析财报、甚至推理物理定律。但它**依然停留在"说"的层面**——告诉你"明天下雨的期望是 12.3mm"。

然后呢？

**防汛响应要启动吗？** **景区要不要关门？** **森林防火等级要不要升一级？**

这些不是数值问题，而是**行动决策**。

这就是为什么我们开发了 **EarthBench**——一个全新的 AI 评测框架，核心问题是：

> *AI 能否利用多源时空观测数据，做出真实世界的环境风险二元决策？*

---

## Decision > Prediction：我们为什么在乎？

气象预报已经非常成熟。GraphCast、WeatherBench 等 benchmark 把"预测精度"卷到了新高度。但精度再高，如果无法转化为有效行动，在灾害防御面前依然不够用。

**举个例子：**

| 维度 | 传统方�� (Prediction) | EarthBench (Decision) |
|------|---------------------|---------------------|
| 输出 | "北京香山明天温度 38°C，湿度 10%，风速 18m/s，FWI=55" | "是否启动香山防火一级响应？ **是，置信度 85%**" |
| 依据 | 多个独立指标 | 综合指标 + 国标阈值判定 |
| 可解释性 | 需要人工汇总判断 | 完整推理链，每一步透明可见 |
| 行动指导 | "你自己决定怎么办" | "建议：加强巡查、清理可燃物、准备灭火设备" |

**这才是从"看数据"到"做决定"的真正跨越。**

## EarthBench 能做什么？

### 覆盖四大高频环境灾种

1. **🔥 森林火险** — 基于 FWI（野火危险指数）、湿度、风速等多指标综合判断
2. **🌊 洪涝灾害** — 24h/6h 降雨量、土壤饱和度、水位趋势三维度交叉验证
3. **🏜️ 干旱监测** — SPI 标准化降水指数 + Palmer 干旱指数融合判定
4. **☀️ 高温热浪** — 湿球温度（Wet-Bulb）为核心指标，比单纯"最高气温"更科学

### 四级难度体系

| 难度 | 典型挑战 |
|------|---------|
| L1 简单 | 单一指标远超阈值，明确预警 |
| L2 中等 | 条件抵消（高 FWI 但有降雨抑制） |
| L3 困难 | 多指标冲突（SPI 和 Palmer 给出矛盾信号） |
| L4 专家 | 时序趋势判断（水位持续上升 / 温度渐进升高） |

### 真实数据驱动

- **NASA MODIS** 卫星遥感数据（地表温度、NDVI）
- **ECMWF** 数值预报模型（FWI、气象预报）
- **中国气象局(CMA)** 降水量、干旱指数
- **地面气象站** 实时监测数据
- **水文传感器网络** 水位、土壤含水率

## 每天都在运行的 AI 决策引擎

我们已经为 **全国 20+ 重点区域** 部署了每日自动风险监测：

从北京香山到长白山，从武汉长江到广州珠江，从哈尔滨到大兴安岭，从重庆到乌鲁木齐……每一天，AI 系统会自动读取最新的多源观测数据，经过**双路推理**（LLM Agent + 启发式规则引擎），给每个区域一份**是/否**的风险评估。

昨天我们看到的结果：

- 监测 **20 个场景**（4 类别 × 5 难度）
- 触发 **8 次预警**
- 整体准确率 **85%**（17/20）
- 平均置信度 **60%**

这意味着什么？意味着 AI 已经开始在一些真实的应急决策场景下，展现出**超越单一规则的判断力**。当然，还有很长的路要走。

## 技术架构概览

```
Scenarios Engine ───→ 定义 20 个测试用例（包含 ground truth 推导规则）
    ↓
Agent Layer ────────→ Rule-based baseline + LLM Decision Agent (qwen3:14b)
    ↓
CARM Framework ─────→ 领域知识增强推理，混合 LLM + 启发式规则
    ↓
Benchmark Engine ───→ 分类别、分难度的精准度统计
    ↓
Publish Pipeline ───→ Markdown + JSON + RSS + Web Dashboard (earth-ai.fun)
```

每一层都是完全开源的，你可以在 [GitHub](https://github.com/showkeyjar/earth-bench) 上贡献代码、提交场景提案、或挑战每日结果。

## 为什么这很重要？

### 对 AI 研究者
你正在见证一个全新的 benchmark 赛道诞生——**Decision Intelligence**。不再是"预测越准越好"，而是"决策越可靠越好"。

### 对气象/应急行业
AI 不再只是辅助画图的工具，而是可以直接提供**决策建议**的系统。每一条预警都附带完整的推理过程和证据链，方便专业人员复核。

### 对普通公众
**免费获取实时的环境风险信息。** 每天醒来看一眼 earth-ai.fun，就知道你家附近有没有火灾、洪水或热浪风险。
