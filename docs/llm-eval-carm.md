- 模式：informed（给阈值摘要）
- 套件：adversarial, basic；limit=全量

## 首例提示词（审计用）

```
判断当前观测是否触发【snow】预警。

【区域】WestLake-Hangzhou
【决策模板】alert
【决策时间窗】72 小时

【观测】
- snowfall_24h = 6.0 mm @ 2026-01-20T12:00:00+08:00（来源 CMA）
- temperature = 0.2 °C @ 2026-01-20T12:00:00+08:00（来源 Station）
- road_surface_temp = -3.0 °C @ 2026-01-20T12:00:00+08:00（来源 Sensor）
- humidity = 85.0 % @ 2026-01-20T12:00:00+08:00（来源 Station）

【判定纪律】
1. 国标阈值查表思维：逐条对照阈值，不是加权平均——平均会稀释 AND 复合条件
2. AND 结构：复合条件（如「降雨 AND 土壤湿度」「降幅 AND 极值」）缺一即不触发
3. 常态 ≠ 异常：北方冬季常态低温、雨季正常降雨、干燥气候常态不构成预警
4. 单位与口径：先核对单位再比较；观测值是瞬时/累计/序列要区分
5. 仅当对人类活动或安全有实际威胁时才 YES

【snow 阈值参考（国标/披露口径）】
24h降雪水当量 ≥30.0mm 特大暴雪；≥10.0mm 暴雪；道路结冰复合：降雪 ≥2.5mm 且路温 ≤0°C；气温 ≥0.5°C 的降水为雨不是雪

【输出格式】只输出一行 JSON，不要任何其他文字：
{"decision": "YES 或 NO", "confidence": 0.0到1.0, "evidence": {"观测变量名": 权重0到1}, "rationale": "一句话判定依据"}
```
